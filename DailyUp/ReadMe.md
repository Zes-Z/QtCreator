# DailyUp
一个置于桌面的极简每日任务清单



---
## 主要操作
* 暂时只有右下角的面板大小缩放
* 日期块的`鼠标点击滑动`,`滚轮滑动`
* 任务清单块的`鼠标点击滑动`,`滚轮滑动`
* 点击日期块,任务列表块,新增任务块**以外的空白处**以拖动整个DailyUp面板
* 右上角`X`关闭
* 左下角`-`最小化
* 点击`Add New Task`新建任务
* 左滑单个任务以选择`删除`
* 右滑单个任务以选择`置顶`或`编辑`

---
## 特殊效果
* 桌面边界回弹效果
* 最长一周的打卡记录

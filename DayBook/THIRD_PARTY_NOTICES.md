## Design references

The information architecture and interaction patterns were inspired by these
open-source personal finance projects. No source code was copied from them:

- Actual Budget - https://github.com/actualbudget/actual
- Cashew - https://github.com/jameskokoska/Cashew
- Money Manager Ex - https://github.com/moneymanagerex/moneymanagerex
- Firefly III - https://github.com/firefly-iii/firefly-iii
- GnuCash - https://github.com/Gnucash/gnucash
- KMyMoney - https://github.com/KDE/kmymoney
- Paisa - https://github.com/ananthakumaran/paisa
- HomeBank - https://homebank.free.fr

The frameless window, glass surfaces, charts and dialogs in this project are
implemented from scratch with Qt Quick / QML.
